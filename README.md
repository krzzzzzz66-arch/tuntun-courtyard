# 🦫 豚豚庭院：陪读物语 (Capy & Friends: Cozy Study Courtyard)

一款专为“一边写作业/工作、一边轻松摸鱼解压”设计的 3D 治愈系桌面动物伴侣游戏。基于 **React + Three.js (React Three Fiber) + Tailwind CSS** 开发。

---

## ✨ 核心特色

1. **📚 写作业陪读专注**
   - 支持番茄倒计时（15分/25分/45分/极速测试）与自由正计时。
   - 专注期间全院圆滚滚小动物自动戴上学霸小眼镜安静陪读，橡果挂机产出翻倍（200%）。
   - 内置作业小便签，每完成一项作业放礼花并获得奖励。
   - 专注完成必得【学霸限定盲盒券 🎟️】。

2. **🖐️ 指尖解压 Q 弹互动**
   - 戳一戳小动物身体会有果冻形变缩放、爱心与清脆音效。
   - 投喂甜柚、烤小鱼干、三色团子，小动物会屁颠屁颠跑过来抢食。
   - 随机挖掘庭院发光宝箱，点击连爆。

3. **🎁 盲盒、繁衍变异与衣橱**
   - 收集水豚、蜜柑圆肥猫、豆柴犬、青团雨蛙、糯米鸭、小熊猫等基础动物。
   - 好感度满 3 颗心后可在爱心木屋进行繁衍，概率孵化出【樱花果冻、宇治抹茶、黄金招财、星空幻梦、冰晶琉璃】等稀有变异！
   - 自由佩戴甜橙、学霸眼镜、樱花环、草帽、荷叶帽、皇冠与状元博士帽。

4. **🌸 四时天光与治愈白噪音**
   - 春日晴樱、黄昏暖霞、夏夜萤火、听雨温泉 4 种 3D 光影与粒子随时切换。
   - Web Audio 合成音效与细雨/温泉水流白噪音陪伴。
